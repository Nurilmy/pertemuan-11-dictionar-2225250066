## Materi Pembelajaran

1. Dasar-dasar dictionary Python.
2. Mengakses data menggunakan `get()`.
3. Menambah, mengubah, dan menghapus data dictionary.
4. Melakukan iterasi menggunakan `items()`.
5. Menggunakan dictionary bersarang (*nested dictionary*).
6. Membuat fungsi untuk mengakses dan mencari data.

## Praktik Pengolahan Data Mahasiswa

File `praktik/data_mahasiswa.py` digunakan untuk mempraktikkan pengolahan data mahasiswa dengan dictionary.

Fitur program:

- Mencari mahasiswa berdasarkan NIM.
- Menambahkan data mahasiswa.
- Memperbarui nilai mahasiswa.
- Menampilkan rekap data mahasiswa.
- Menghitung rata-rata nilai mahasiswa.

## Cara Menjalankan Program

1. Pastikan Python sudah terinstal.
2. Buka folder proyek di Visual Studio Code.
3. Buka file Python yang ingin dijalankan.
4. Jalankan program melalui terminal:

```bash
python praktik/data_mahasiswa.py
```

Untuk menjalankan latihan, gunakan contoh berikut:

```bash
python latihan/01_dasar_dictionary.py
```
